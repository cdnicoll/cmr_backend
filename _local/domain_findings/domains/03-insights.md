# Domain: Insights

## Purpose

The Insights domain extracts **structured intelligence** from scraped content using an AI agent. It identifies entities (companies, commodities, people, etc.), relationships, market signals, and scores each insight for importance, originality, reliability, and relevance.

## Core Behavior

1. **Queue insight processing** (`POST /api/v1/resources/insight`):
   - Queries resources where: `scrape=true`, has `job_id` with `data_id`, `insight_status='pending'`, within publication window
   - Atomically marks selected resources as `insight_status='processing'` (prevents race)
   - Queues one Celery task per resource

2. **Insight task flow** (Celery `process_resource_insight`):
   - Fetches scraped data from Apify using `data_id`
   - Extracts metadata (title, channel, content text) — different logic for YouTube vs website
   - Validates content length (min 100 chars)
   - Runs insight agent (PydanticAI, gpt-4o) to produce `ResourceAnalysis`
   - Stores `insight` JSONB, `title`, `channel`, sets `insight_status='completed'`

3. **Insight agent output**: `ResourceAnalysis` with:
   - `resource_overview` (summary, tags)
   - `resource_insights` (array of insights with category, scores, evidence, entities, relationships)
   - `entities`, `relationships`, `temporal_context`

## Key Data

- **Insight categories**: market_opportunity, risk_factor, trend_identification, competitive_intelligence, regulatory_impact, technical_analysis, fundamental_shift, sentiment_indicator
- **Entity types**: commodity, company, institution, person, location, concept, event
- **Relationship types**: influences, influenced_by, competes_with, partners_with, owns, located_in, mentioned_in, related_to
- **Scores**: importance, originality, reliability, relevance (each: value, rationale, confidence)

## Boundaries

- **Depends on**: Apify dataset service, Insight agent (PydanticAI), PostgreSQL
- **Depended on by**: Graphiti (ingests resources with insights)

## Edge Cases and Notable Logic

- **Race condition prevention**: `UPDATE ... RETURNING` atomically selects and marks `processing`
- **Stuck processing**: `reset_processing_resources(max_age_minutes)` resets `processing` → `pending`
- **Scraping failures**: On `ApifyDatasetError`, disables scraping for resource and marks `insight_status='failed'`
- **Content too short**: Marks failed, no retry
- **JSON parsing retries**: Insight agent retries up to 2 times on JSON errors
- **Alignment score**: Explicitly NOT generated by insight agent ("will be added by different process")

## What to Preserve

- Entity/relationship taxonomy and scoring dimensions
- Atomic selection + status update pattern
- Stuck-processing reset with configurable timeout
- Permanent failure handling (disable scrape, mark failed) for scraping/validation errors
